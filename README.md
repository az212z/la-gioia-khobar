# La Gioia — Al Khobar

Independent website design by Ali.

## Run
Node.js 24 LTS. `npm ci`, `npm run dev`. Validate with `npm run typecheck`, `npm run lint`, `npm run build`. Static export: dist/client. GitHub Actions builds with GITHUB_PAGES=true and publishes dist/client/la-gioia-khobar. No secrets, server, customer-data collection or simulated bookings.

## Content
Menu: data/menu.json; restaurant details: data/restaurant.json; printable menu: public/menu.html. Keep the printable and interactive menu synchronized on updates.

All87availablepublicentries in13categories. Hidden summer/breakfast categories and unavailableitems excluded using native flags, consistent with full renderedbrowsermenu. Actual publishedbase prices used; noactivebranchpriceoverrides.

Official Linktree points hosted iWaiter menu,Maps,Instagram anddelivery. No standalone official website found. Same-named sites in Houston andTurkey are unrelated restaurants.

Repository inventory checked against 891 repositories on az212z, 8 September 2026. Search indexing cannot guarantee absence in unindexed content.

## WhatsApp contact button

The floating WhatsApp link uses the restaurant’s published telephone number in international digits-only format, separately from the designer credit. La Gioia explicitly publishes this as WhatsApp in its official iWaiter data. WhatsApp registration of the other published numbers has not been independently confirmed; a valid click-to-chat URL does not establish an active WhatsApp account.
